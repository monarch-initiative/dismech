# Omsk Hemorrhagic Fever fallback research notes

## Provider attempts

- `just research-disorder claude_code Omsk_Hemorrhagic_Fever` failed before any
  report was written because the local Claude Code workspace trust dialog had
  not yet been accepted for this repository.
- `just research-disorder openscientist Omsk_Hemorrhagic_Fever` was attempted
  twice. The first run stayed silent for roughly six minutes; the second run was
  allowed to run for roughly ten minutes. Neither produced a staged
  `Omsk_Hemorrhagic_Fever` report or citations file under `tmp/research-staging/`,
  so both were interrupted before curation proceeded.
- `just research-disorder-cyberian-codex Omsk_Hemorrhagic_Fever` was attempted
  after installing the standalone `agentapi` helper into this isolated
  worktree. Cyberian reached the local AgentAPI server, but the server returned
  HTTP 500 on the first `/message` call. A preserved debug server showed Codex
  stopped at its update prompt and, after that prompt was skipped, AgentAPI
  still reported `status: running`, so ordinary `type: user` messages could not
  be delivered to the agent.

  prevention and treatment history.

  replication anchor.
- PMID:31668201 — 2019 viral-hemorrhagic-fever review with a concise OHFV
  clinical summary.

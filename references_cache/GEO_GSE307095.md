# RNA-seq profiling of resting naive and CD27bright memory B cells and in vitro activated CD27bright memory B cells reveals differences in B-cell activation patterns in common variable immunodeficiency (CVID)

## Content

To investigate the transcriptional differences during resting state and B-cell activation in healthy donors and patients with CVID, we sorted naive B cells and CD27bright memory B cells from the two groups and examined the resting state and TLR9 agonist (CpG)-activated CD27bright memory B cells.

## Definition

Schizophrenia is a long-term, severe mental illness causing a range of different psychological symptoms, such as hallucinations and delusions. It includes schizophrenia, schizotypal and delusional disorders.

# ICD-10 and Read code definitions

These definitions include schizophrenia-related disorders such as schizophrenia, schizotypal and delusional disorders. They have been co-developed with expert clinicians and previously published (John et. al. 2018; John et. al. 2022).

This definition has been created by mapping the existing Read code and ICD-10 definitions and additional exploration of SNOMED CT codes.

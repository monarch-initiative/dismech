## Normal function

PEX11B is not part of the import machinery. It is a peroxisomal membrane
protein whose N-terminal amphipathic helix deforms and elongates the
peroxisomal membrane, so that the dynamin-like GTPase DLP1 can divide it;
peroxisome number is set by this division of existing organelles.
ai-gene-review gives its core molecular function as
<span class="result" data-compare="names" data-code="g.core_function_terms('molecular_function')">protein homodimerization activity<span class="method"></span></span>,
acting in
<span class="result" data-compare="names" data-code="g.core_function_terms('directly_involved_in')">peroxisome fission; and regulation of peroxisome size<span class="method"></span></span>
at the
<span class="result" data-compare="names" data-code="g.core_function_terms('locations')">peroxisomal membrane<span class="method"></span></span>.
